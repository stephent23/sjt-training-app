Each page carries a small dashed switcher at the top for its alternate states (empty, loading, error); that switcher is mock chrome and not part of the design. Everything responds to prefers-color-scheme, so switch your OS theme to see the dark palette.

What is not shown

Run session and Review are described in the plan (§4.4, §4.5) but not mocked — Run session is a simpler variant of the lift header plus the structure list, and Review keeps the existing mono tables almost unchanged, which is the point being made about it. Nothing here uses a webfont: production self-hosts Plus Jakarta Sans, so the real thing will look rounder and friendlier than these system-stack renderings.

Data is real. Exercise names come from seeds/exercises.sql, the weekly shape (Lift A · Easy run · Lift B · Intervals · Long run) from seeds/week1_sessions.sql, and the goal tags from GOAL_TAG_GROUPS in src/types.ts. Dates are placed in week 4 of an ongoing block so completed, in-progress, skipped and planned states all have somewhere to appear.
