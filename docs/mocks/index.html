What changed from the first pass

Notes

The first pass read as childish, and the causes were specific: a rounded typeface in the stack, 22px card radii with 999px pill buttons, weight 800 on almost everything, three saturated hues at once, and filled numeral circles. All reversed. Hierarchy is now carried by size and colour rather than by making everything bold, and elevation is a hairline rather than a shadow.

Two contrast failures were found and fixed while building this: the muted ink carrying the eyebrows and figures measured 3.7:1 in light and 4.2:1 on the raised dark surface, both under AA at 11–12px. See §3 of docs/design-rethink.md.

Run session and Review are described in the plan but not mocked — Run session is a trimmed lift header plus the structure list, and Review deliberately changes least.
